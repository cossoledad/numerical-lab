# Numerical Lab 学习指南

## 1. 从高中数学到计算数学

高中阶段习惯的问题形式通常是：

```text
已知公式
→ 推导解析表达式
→ 手工计算
```

进入大学以后，需要建立新的思维：

```text
现实问题
→ 数学模型
→ 数值方法
→ 算法
→ 程序
→ 近似结果
```

重点变化是：

> “没有漂亮的解析解”并不代表问题无法求解。

---

## 2. 求根：从方程变成迭代

问题：

```text
x³ + x - 1 = 0
```

高中思维可能首先尝试：

- 因式分解
- 特殊根
- 代数公式

数值思维则是：

```text
能否构造一系列越来越接近根的数？
```

二分法使用：

```text
区间不断减半
```

Newton 法使用：

```text
切线不断修正近似值
```

这对应 C 中的循环：

```c
for (...)
{
    ...
}
```

因此：

> 循环不仅是“重复打印”，还是数值算法中“逐步逼近答案”的核心机制。

---

## 3. 积分：从原函数转向有限求和

定积分：

```text
∫[a,b] f(x) dx
```

不必总是先求原函数。

计算机可以直接做：

```text
将区间分成 n 份
→ 每份计算一个近似面积
→ 累加
```

即：

```text
积分
≈
有限求和
```

这也是极限思想的程序化表达。

---

## 4. 导数：极限如何落地为程序

数学定义：

```text
f'(x) = lim[h→0] (f(x+h)-f(x))/h
```

计算机无法真正令 `h = 0`。

因此只能：

```text
选择一个很小但不为 0 的 h
```

这带来第一个重要的数值分析问题：

```text
h 越小一定越好吗？
```

答案：不一定。

因为计算机使用有限精度浮点数。

---

## 5. ODE：给变化规律，不必给显式函数

Newton 冷却：

```text
dT/dt = -k(T-Tenv)
```

Euler 法的思想：

```text
下一时刻
≈
当前值
+
当前变化率 × 一个很短的时间
```

写成：

```text
T_next = T + dt * dT_dt
```

这就是微分的几何意义直接变成了程序。

---

## 6. 矩阵：数组开始表达大学数学对象

线性方程组：

```text
Ax = b
```

矩阵 `A` 可以存储在连续内存中：

```text
A[row * cols + col]
```

这时学生应重点理解：

```text
二维数学对象
≠
计算机里必须真正存在二维内存
```

程序可以使用一维连续内存表达二维矩阵。

---

## 7. 指针为什么重要

指针不要仅理解为：

```text
“保存地址的变量”
```

更重要的是它解决：

```text
函数如何操作调用者的数据？
```

以及：

```text
程序运行前不知道需要多少内存怎么办？
```

矩阵模块就是动态内存的典型应用。

---

## 8. 函数指针为什么重要

数值算法通常不应该写死某个函数。

例如积分程序需要的是：

```text
一个算法 + 任意 f(x)
```

因此 API：

```c
double integrate(MathFunction f, ...);
```

表示：

```text
积分算法与具体数学函数分离
```

这是非常重要的软件设计思想。

---

## 9. struct 为什么重要

例如求根算法不仅产生一个数：

```text
root
```

还需要：

```text
是否收敛
迭代次数
残差
```

于是：

```c
typedef struct
{
    double root;
    double residual;
    int iterations;
    int converged;
} RootResult;
```

这说明：

> 结构体是把“属于同一个概念的数据”组织在一起。

---

## 10. 数值结果永远要问三个问题

不要只问：

```text
结果是多少？
```

还要问：

### 1. 准确吗？

误差有多大？

### 2. 稳定吗？

输入稍微变化，结果会不会剧烈变化？

### 3. 代价是多少？

时间和内存消耗是否合理？

这三个问题会贯穿之后的：

- 数值分析
- 科学计算
- 工程计算
- 机器学习
- CAD/CAE
- 仿真
- 图形学
